## What this room covers

This room teaches us the basics of the command-line interface (CLI) in Windows. We acts as a new intern at a cyber-security firm and we learn the basics of the Command Prompt (CMD) on Windows

## Key concepts learned

- Command Prompt (CMD) — is a text-based interface that is used by professionals in order to move around and perform tasks in Windows, you type commands and the result is also in the form of text but it is much more quicker (once you become comfortable) and gives much more control hence it is used

## Tools/commands used

- cd — just using "cd" alone without anything coming after it we print the directory we are currently in while on the other hand cd is also used to change the directory (when you place the directory after the cd ) for example cd Documents takes you to the Documents folder
- dir — it is used to list all visible files in a directory just like when on GUI you open a folder and see all the files inside it similarly on the command prompt you type "dir" to see all the files inside a directory/folder
- dir /a — is used to show all the files in the folder including the hidden files as well
- type/more — it is used to read a file let's say you have a txt file that you want to read (names.txt) in GUI you would open it by double clicking while in the cmd you simply write "type or more" followed by the name of the file and you can read it right there in the terminal
- whoami — it is a command that tells you who you are logged in as for example let's say you are logged in as User1 so running the command will give you "User1" as the response
- hostname — is used to see the name of the computer being used
- systeminfo — gives you useful information about the OS like the OS you are on, the version and the type etc and other information as well
- ipconfig — is used to see the information about the intenet network connected to the PC including useful information like IP Address, Gateway, IPv4 and IPv6 etc
- dir /s (file name) — is used to search for a file in your current directory
