## What this room covers

This room covers the fundamentals of Cloud Computing, it is a technology that is built on technologies we have learned before this: Virtualization, Containers etc. So the basics of Cloud computing is that we use computers and servers over the internet instead of buying them physically ( in virtualization we divided our computer into different computers or operating systems, while in Cloud Computing we simply use these computers online ). The reason why this is useful include the following:

Costs: You don't need to buy a whole computer every time you need to do something or even create many VM's on your computer, you simply buy one online and use it until you need it and once you don't need it you simply stop using it so it is a much cheaper way than using physical computers or VM's ( basically you only buy the things you need and nothing else )

Scalability: You don't need to create everything by yourself if you need to scale you simply buy a server or whatever type of computer you need and put your data on it and that is it

Global Access: User from across the globe can easily access your application or whatever service you are providing

Security: It is made sure that cloud computers are as secure as they can be and even if there is some kind of risk to the security the cloud providers have to deal with it and not you

## Key concepts learned

Types of Cloud

- Public Cloud — It is a type of cloud that is used by multiple people and organizations and it is mainly used by startups, websites and global apps because it is easily scalable, affordable and doesn't need any infrastructure
- Private Cloud — It is used mainly by a single company or organization and is much more secure and confidential. It is mainly used by banks, healthcare, and government organizations because it offers great control and customization and has better security and compliance for sensitive data
- Hybrid Cloud — It is a mixture of both types mentioned above it is used by companies that need to secure their private data and also want to scale publically easily

Cloud Service Models

- Infrastructure As A Service (IAAS) — In this model the service provider is responsible for the physical hardware while everything else is done by the user (from configuring the OS to creating and deploying applications etc)
- Platfrom As A Service (PAAS) — In this model the service provider is responsible for the physical hardware as well as the OS and the user just needs to build, deploy and run his applications ( everything else is handled by the service provider )
- Software As A Service (SAAS) — In this model the service provider provides you with a completely built software that you can access through the browser etc and you basically don't need to do anything
